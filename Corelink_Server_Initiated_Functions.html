Server Initiated Control Functions

Name:update

Description:update a receiver with a new stream from sender

argument description type sample default
function function that was triggered string update undefined
receiverID receiverID that matched the new sender string 0 undefined
streamID streamID that was updated string 0 undefined
user username of for the stream that is announced string 0 undefined
apps list of app names that have processed this stream array 0 undefined
type the type of the stream (e.g. 3d, audio) that was updated string undefined undefined
meta metadata from the sender stream string undefined undefined
token optional token to authenticate the message string undefined undefined
